# micro.css

A tiny, classless CSS framework.

## Why?

I don't like having to write styling for my projects so I just made this so I can have a simple stylesheet that I can use for all my projects and not write styling in my html. I also wanted to make something that was small and easy to use.

## Features
- is only 985B (and that's formatted)
- has a single file with no dependencies
- is classless, so you can write semantic HTML without thinking about the styling

## Usage

Just put the micro.css file in your project and link it in the head of your html:

```html
<head>
    <link rel="stylesheet" href="micro.css">
</head>
```
